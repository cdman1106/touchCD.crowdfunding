# touchCD 先行予約

アーティストごとの作品一覧と、作品ごとの先行予約ページを運営します。個別ページは `/artists/アーティストのURL名/作品のURL名` です。同じアーティストの作品は同じアーティストURL名と名前で登録します。配布済みリンクを維持するため、保存後のURL名とアーティスト名は固定です。

## 管理画面

`/manage` で「新規作成」を選び、名前・作品名・写真や楽曲のURL・受取日時・予約締切を入力します。「下書き」「リンク限定」「作品一覧に掲載」のいずれかで保存できます。リンク限定の作品は作品一覧やアーティスト一覧から除かれ、URLを知っている人がアクセスできます。サイト自体のアクセス制限は引き続き適用されます。

予約の初期条件は、無料予約15個で支払い案内、入金12個で製造、上限25個です。作品別に変更でき、外部で受け付けた数の加算、予約の訂正、入金済みの記録、CSV出力に対応します。

## ローカル実行

Node.js 22.13以上で `npm run dev` を実行し、表示されたURLを開きます。ローカルのデータはプロセス終了時に消えます。サンプル作品のメールアドレス欄には形式を試すためのアドレスを入力できます。入力したアドレスはサーバーへ送信されません。

## Cloudflareで本番受付

1. CloudflareのD1で `touchcd-reservations` を作成します。
2. Workers & PagesでGitHubリポジトリ `cdman1106/touchCD.crowdfunding` をインポートし、Worker名を `wrangler.toml` の `name` と合わせ、本番ブランチを `main` にします。デプロイコマンドは `npx wrangler deploy` です。ビルドは `wrangler.toml` に設定してあるため、ダッシュボードのビルド欄は空欄にできます。
3. 新規の空のD1は、サイトの初回アクセス時にWorkerが予約用テーブルを作成します。既存のD1に追加のマイグレーションを適用する際は、D1 Edit権限がある認証済みのWranglerで `npx wrangler d1 migrations apply touchcd-reservations --remote` を実行してください。
4. Workerの「Variables and Secrets」で、24文字以上のランダムな `ADMIN_TOKEN` をシークレットとして設定します。ローカルから行う場合は認証済みのWranglerで `npm ci`、`npm run deploy` の順に実行し、`npx wrangler secret put ADMIN_TOKEN` で管理キーを設定します。
5. `/manage` で作品と予約条件を登録します。問い合わせ先・作品紹介・商品写真・公開範囲・未来の予約締切・受取条件が入力されていることを確認し、その作品の受付を有効にします。
6. 下記のメール送信方式を設定してから `RESERVATIONS_OPEN=1` を設定すると、作品単位で有効にした予約受付が始まります。Cloudflareの設定ではサンプル作品を表示しません。`PREVIEW_DEMO_ADMIN` はローカル確認専用です。

旧バージョンで `CAMPAIGN_JSON` に登録した作品は、従来の予約と設定を保持して読み込みます。予約者データは保護された管理画面に表示します。支払い案内・決済・返金は手動運用です。

## メール認証と会場受取

共通設定として、認証コードの署名用の `EMAIL_VERIFICATION_SECRET`（32文字以上のランダムな値）をシークレットに保存します。次のどちらかの送信方式を設定し、`RESERVATIONS_OPEN=1` にすると本番予約を受け付けます。

- Gmail — `MAIL_PROVIDER=gmail`、送信元の `GMAIL_FROM`、Google CloudのOAuthクライアントの `GMAIL_CLIENT_ID` を設定します。 `GMAIL_CLIENT_SECRET` と `GMAIL_REFRESH_TOKEN` はシークレットに保存します。Gmail APIを有効にし、送信元と同じアカウントから `https://www.googleapis.com/auth/gmail.send` のオフラインアクセスを許可してリフレッシュトークンを発行します。
- Resend — `MAIL_PROVIDER=resend`、`MAIL_FROM`（認証済みドメインのアドレス）を設定し、`RESEND_API_KEY` をシークレットに保存します。

無料予約ではメールに届く6桁のコードを使用します。コードは10分間有効で、一度使うと無効です。管理者が管理画面で「入金済み」を保存すると、認証済みアドレスに支払い完了メールを送ります。メールの送信に失敗した場合は入金記録を保持し、同じ予約から送信を再試行できます。

当日はファンが受付にメールを提示し、スタッフは管理画面で作品を選んで受取コードを照合します。入金済みの表示を確認して「受取済みにする」を押します。受取済みの予約は再度処理できません。入金記録は現在の管理画面から手動で行います。

`/pickup-example` に支払い完了メールのサンプルを表示しています。サンプル作品の予約フォームでは実際のメールを送信せずに認証を体験できます。

## 支払い案内

管理画面で作品を選び、「支払い案内の設定」で支払期限（日本時間）と、1個注文用の共通決済リンクを保存できます。案内を作るには無料予約の目標数に達していることと、将来の支払期限が必要です。2個以上の注文用には、予約一覧の「支払い案内」に該当個数分の個別決済リンクを登録します。個別リンクは共通リンクに優先します。

「案内文を作る」で作品、個数、税込総額、支払期限、決済リンクを含む件名と本文をコピーできます。支払い案内の送信と決済サービスでのリンク発行は手動です。作品のサンプルにある「支払い案内の見本を見る」で文面を試せます。
