# touchCD D案 — 既存リンク活用型

## 方針
アーティストがすでに持つ公式HP、SNS、音楽配信サービス、リンクまとめページ等のURLへNFCから直接接続。専用音楽サイトの新規制作なし。

## 今回の設計案
- 1デザインにつき指定URL1つ。複数リンクは既存のlit.link等を指定。接続先は企画相談時に確認し、製造・書き込み・検品後に納品。
- 既存の予約、決済、製造、配送、精算は共通。公式予約サイトの再販売希望受付は共通化予定。
- 外部URLへ直接アクセスするため、A〜Cの5年サイト契約、専用サイトAI、アクセス分析、広告非表示、所持者限定閲覧は対象外。外部サイトの利用条件・公開状態に依存。
- D案の基本代、ファン向け価格、納品後のURL変更、NFC書き換え可否、リンク切れ対応・管理型リダイレクトの要否は未決定。利益試算はA〜Cの基本代による参考値として表示。
- 相談フォームの企画診断にD案・接続先URLを追加。URLはHTTP(S)の入力を確認し、相談内容に文字列として含める。実際のNFC書き込みや外部接続の自動実装ではない。
