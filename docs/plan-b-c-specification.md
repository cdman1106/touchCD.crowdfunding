## B固有の設計案
- 1作品/販売企画単位の独立ページ。新作が別のページへ影響しない。アルバム、ライブ、周年等の独自コンテンツを登録。
- 公開前はアーティスト登録・編集・予約公開。公開後は通常の差し替え・追加を標準対象外とし、誤記修正、権利上の削除、予定済み公開などの例外を検討する。修正の料金/範囲、アーティスト自身の緊急非公開の権限は未確定。
- 各作品の最終販売日から5年。同一作品再販で更新、別作品販売で更新しない案。
- 有料延長月1,650円/サイト、期限後再開11,000円/サイト＋新規販売または延長契約を提案。サイト停止時は該当サイト閲覧停止。複数サイトの請求方法・収益性を要確認。
- Bの作品一覧はアーティスト管理画面と公開公式予約サイトを基盤にする。B記念サイト内では他作品の案内を掲載できても、別の記念サイトの閲覧権を付与しない。

## C固有の設計案
- A共通サイトに、Bの記念サイトを追加。アーティスト版NFC→共通のみ、記念版NFC→該当記念＋共通のみ。他の記念版への横断閲覧不可。共通サイト上の作品一覧・再販希望は閲覧権の付与を意味しない。
- 共通サイトはアーティスト版・共通閲覧権付き記念版の最後の販売日から5年、記念サイトは同じ記念作品の最後の販売日から5年。新しい別の記念版で古い記念サイトは延長しない。共通が有効なら記念停止後も記念版のタッチから共通へ案内する案。逆の場合は該当記念の閲覧のみ。
- 共通・各記念サイト単位で延長月1,650円・再開11,000円を提案。広告非表示は全サイト合算月3,300円、AIは全サイト合算月30回無料＋追加30回330円。サイト単位にAI無料枠・広告請求を増やさない。
- 1サイトだけの停止で他サイトのAI残高を消去しない案。全対象サイト停止時のみAの無料消去・付与停止・有料保存を流用する。課金/停止時の条件は未確定。
- 管理画面はサイト切替・公開設定・分析・作品一覧・再販管理を共通化。共通サイトに販売作品を自動掲載し編集可能。記念ページから共通サイトへのアクセスは認証セッションの権限を確認。
